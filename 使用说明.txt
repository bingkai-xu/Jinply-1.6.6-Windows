Jinply for Windows
Version 1.6.6

Double-click Jinply.bat. Jinply starts on this computer and opens in its own window, with no address bar and no browser tabs. Close the window to quit. Node.js does not need to be installed separately.

The interface opens in English. The language can be changed from the menu inside the app.
